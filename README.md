# Python Programming Practice

## About This Repository

This repository contains five beginner-friendly Python programming projects. These programs help improve logical thinking, problem-solving skills, and understanding of Python fundamentals.

## Projects Included

| No. | Project Name | Description |
|---|---|---|
| 1 | Count Vowels in a String | Counts the total number of vowels in a given string. |
| 2 | Palindrome String Checker | Checks whether a string reads the same forward and backward. |
| 3 | Smallest Number Finder | Finds the smallest number from a given list. |
| 4 | Even and Odd Counter | Counts the number of even and odd numbers in a list. |
| 5 | Factorial Calculator | Calculates the factorial of a given number using a loop. |

## Technologies Used

- Python
- Visual Studio Code
- Git
- GitHub

## How to Run the Programs

1. Clone or download the project.
2. Open the project folder in Visual Studio Code.
3. Open the terminal.
4. Navigate to the folder containing the Python files.
5. Run the required program.

Example:

```bash
python 206.py
```

You can replace `206.py` with the filename of another program.
